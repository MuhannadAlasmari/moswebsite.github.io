Projects (ML Section coming soon!)

Smart Muratel, known as "المرتل الذكي" in Arabic is a voice generation and text annotation system for Quranic translations. The user signs in/signs up to create an account, creates a project by naming it and selecting the language to translate it to.


When getting into the home page, the user selects a surah, chooses the voice they want to generate with, the verse, and even add tags to make pronounciations more accurate to that of the Arabic language.


You can find the final report for the project in "Interests." Click on the project's icon to go to it.
